What is a Board Manager?

As a Board Manager you control a single IdeaMinit board directly from the board page — no separate admin login is needed. You can customise the board, manage its lanes (columns), moderate submitted content, lock the board when collection is complete, and export the results. All you need is your Manager Code, provided by your Site Manager.

1 · Unlocking your board

1
Open the board URL in your browser

If the board is protected by a User code, you will be asked to enter it before seeing the board content.

2
Click the settings gear icon

It is in the top-right corner of the board header.

3
Enter your Manager Code

The Manager code is the 8-character code given to you by your Site Manager. Manager controls — editing, lane management, moderation, and export — become visible as soon as the code is accepted.

💡 Shared or meeting-room devices A Manager-code unlock is held in the current tab's memory. Refreshing clears it, so you must enter the code again. Exception: a Site Manager who is still signed in is automatically unlocked again. On a shared device, sign out of site administration first; closing its tab alone does not sign you out.
💡 Site Managers A signed-in Site Manager is automatically given manager controls when opening a board from their own site. No Manager code or User code is required in that case.
Signing out of site administration Site Manager sign-in can survive closing and reopening the browser, with a 24-hour token lifetime. Use Sign out on the administration page to remove management access from every open board tab on the same application origin in that browser, including tabs unlocked with a Manager code. Management dialogs close. Public boards stay available for participation; protected boards require separate participant access. A different browser or device is not signed out by this action.

→ How participants experience the board

Knowing what participants can and cannot do helps you run smoother sessions and answer questions on the spot.

👤 Identity & anonymity

Participants can enter a name when posting an idea or comment, but it is optional. Leaving it blank posts as Anonymous. The name is free text — it is not verified or linked to any account. As moderator, you see whatever name was typed, which may be nothing. This is intentional: it encourages candid feedback in staff sessions.

👍 How voting works

Participants vote on idea cards. Key behaviours to know:

  • One vote per idea per browser identity — they can click again to remove it
  • No limit on how many different ideas they can vote for
  • The browser identity is stored in a signed, long-lived cookie; it is not a user account
  • A different browser or device receives a different identity and may vote on the same idea
  • There is no vote-only off switch; Read-Only stops voting, idea submission, and comments together

Treat vote totals as directional, not as a precise ballot.

2 · Editing board details

When unlocked, click the pencil icon beside the board title to open the inline editor. Click the checkmark to save or the X to cancel. The information icon beside the title opens the optional board description.

FieldWhat it controls
Title The large heading at the top of the board page, seen by all participants
Description Optional instructions or context, opened with the information icon beside the board title
"Add Idea" button label The text on the main submission button (e.g., "Submit a suggestion", "Share feedback")
Language Selects English, Finnish, or Swedish for built-in interface labels. Existing titles, descriptions, lane names, ideas, comments, and custom button text are not automatically translated.
Lock board (read-only) Stops new ideas, votes, and comments while keeping the existing board visible

Click the checkmark to apply changes. If another open tab still shows old header details, reload it.

3 · Managing lanes

Lanes are the columns participants sort ideas into. Click Manage lanes to open Lane Settings. Set up clear names and a useful order before inviting participants.

✚ Add a lane

Click Manage lanes, enter a name and colour under Add New Lane, then click Create Lane. The new lane appears immediately.

✎ Edit a lane

Open Manage lanes and click the pencil icon beside a lane. Change its name or colour and click Save lane.

🗑 Delete a lane

Open Manage lanes, click the trash icon beside a lane, and confirm. All ideas currently in that lane are permanently deleted.

Reorder lanes

Use the up/down arrows beside a lane. Each move saves automatically; wait for the saving indicator to finish. First/last boundary arrows are disabled. Save or cancel an open lane edit before moving lanes.

The order persists after reload and is shared by desktop columns, mobile tabs, and lane selectors. A duplicated board keeps the saved lane order; new lanes go at the end. This does not change the Sort setting for ideas.

⚠ Before deleting a lane Move any ideas you want to keep to another lane first. Deletion removes the lane and all its ideas permanently.

4 · Moderating content

Moderation controls appear on every idea card while you are logged in as board manager.

✎ Edit an idea

Click the pencil icon on an idea card to edit the title or description inline. Click Save to confirm. Use this to fix typos or clarify unclear submissions.

↔ Move an idea to another lane

Drag and drop (desktop): Hover the card to reveal the grip handle (⠿) at the top-left. Drag the card to any other lane column — the target column highlights as you hover over it — then release to drop.

Edit mode (any device): Click the pencil icon and use the lane picker at the bottom of the form, then click Save.

⇅ Sort ideas

Use the Sort dropdown in the board header to reorder ideas within every lane at once:

  • Oldest first — submission order (default)
  • Newest first — most recent at the top
  • Most votes — highest vote count first, useful at the end of a session to surface the most popular ideas

🗑 Delete an idea

Click the trash icon on an idea card and confirm. This permanently removes the idea and all comments on it.

🗑 Delete a comment

Expand the idea's comments and click the trash icon beside the comment you want to remove. Use this for inappropriate or off-topic responses.

⛔ Deletions are permanent Ideas and comments cannot be recovered once deleted. Export the board data first if you may need a record.

5 · Locking the board (Read-Only mode)

When the idea collection window closes, lock the board to prevent new submissions while keeping all content visible to participants.

1
Make sure your manager session is active

The pencil beside the board title should be visible. If not, unlock manager controls first (see Section 1).

2
Click the pencil beside the board title
3
Toggle the Lock board switch

Turn on the switch, then click the checkmark to save. An amber banner identifies the read-only board. Other open tabs may need to refresh their board details to show it; the server enforces the saved restriction on new ideas, votes, and comments.

4
To unlock, toggle the switch off

Click the checkmark to save again. Submission, voting, and commenting are allowed again unless another access restriction applies.

6 · Exporting board data

Export the contents of the board for reporting, analysis, or a reference copy before making large changes. Exported files are not a one-click restore mechanism; there is no import/restore-from-file screen. Do not assume the row order in a download matches the saved visual lane order.

FormatBest for
CSV Spreadsheets (Excel, Google Sheets) — includes separate idea and comment rows with lane, content, author, vote/comment totals, and timestamps
JSON Developer use, automated tools, or a complete data backup including comments
1
Make sure your manager session is active
2
Click the Export button in the board header
3
Choose CSV or JSON

The file downloads immediately to your downloads folder.
