App administration
App Manager
Manage customer sites and the Site Managers assigned to them

The App Manager oversees the whole IdeaMinit installation. This role creates and controls sites and Site Manager accounts, but does not manage the boards inside a site. Site Managers handle their own boards.

🔐 App Manager · Logging in

1
Open the App Manager login page

Go to the application URL and append /app-manager.

2
Enter the App Manager email and password

These installation-level credentials are configured by the application operator.

3
The Sites dashboard opens

Each site shows its status and the number of boards and Site Managers it contains.

▦ App Manager · Managing sites

✚ Create a site

Click New Site, enter a descriptive site name, and click Create. The new site starts as active.

✎ Rename a site

Click the pencil beside the site name, enter the new name, and save it. Press Escape or click the X to cancel.

⏸ Put a site on hold

Click the pause control. All boards on the site become unavailable to visitors until the site is reactivated with the play control.

🗑 Delete a site

Click the trash control and confirm. This permanently removes the site and its associated boards and manager accounts.

⛔ Site deletion is permanent Put a site on hold when access should only be suspended. Delete it only when its data is no longer required.

▦ App Manager · Active-board limits

Each site shows Active boards: used / limit. New sites default to Unlimited. Click Set board limit on the site card, then either leave Unlimited active boards selected or clear it and enter a whole number in Maximum active boards. Click Save limit.

  • Zero is allowed and prevents additional active boards. Negative numbers and decimals are not accepted.
  • Only boards that are neither archived nor in Trash count. Read-only boards and boards on a site that is on hold still count.
  • At the limit, creating or duplicating a board is blocked. Unarchiving or restoring from Trash is also blocked when it would add an active board.
  • Restoring an archived board from Trash does not add an active board; it returns to Archive.
  • Lowering the limit below current usage does not delete, archive, or disable existing boards. Archive a board or increase the limit before adding another active board.
Site Managers cannot change this limit Ask the App Manager to change the limit. A Read-Only switch does not free an active-board slot.

👥 App Manager · Managing Site Managers

1
Expand the relevant site

Click the arrow at the left of the site row to show its Site Managers.

2
Click Add Manager and enter an email address

IdeaMinit creates the account and generates a temporary password.

3
Copy and deliver the credentials securely

The generated password is displayed only once. The Site Manager can later use Forgot password? on the Site Manager login page to set a new password.

⚠ Removing a Site Manager The trash control beside a manager removes that account from the site. Make sure another Site Manager remains if the site still needs administration.

Part 1
Site Manager
Full administrative control over all boards on your site

Site Managers have access to the admin panel and can create, configure, archive, and delete any board on the site. Board Managers only control individual boards and cannot access the admin panel.

🔐 1 · Logging in

1
Navigate to the admin login page

Go to the application URL and append /admin.

2
Enter your email and password

Use the credentials provided by your App Manager or application operator. If you have forgotten your password, click Forgot password? to request a reset link by email.

3
You are taken to the Boards dashboard

All active boards for your site are listed here. Use the top navigation to switch between Boards, Archive, and Trash.

⚠ Rate limit After 10 failed login attempts in a minute the form is temporarily locked. Wait a moment before trying again.
Sign out on shared devices Site Manager sign-in is remembered in this browser and can survive closing and reopening Chrome. The sign-in token expires 24 hours after login; closing the admin page is not sign-out. Use Sign out in the administration header. This removes management access from every open board tab on the same application origin in this browser, closes management dialogs, and prevents a delayed unlock response from restoring access. Public boards remain available to participants; a code-protected board needs separate participant access. Other browsers and devices are separate sessions.

✚ 2 · Creating a board

1
Click New Board

The button appears in the top-right corner of the Boards dashboard.

2
Set up the board

Choose the board language, then enter the title, optional description, submit-button label, and optional User code. Leave the User code blank for open access. After creating the board, add lanes from the board manager view.

3
Click Create Board

IdeaMinit creates a unique board URL and an 8-character Manager code. Both remain available on the board card in the Boards dashboard. Copy the URL for participants and share the Manager code only with the person responsible for managing the board.

💡 Tip The board card also shows whether access is open or protected by a User code. Copy controls are available for the board URL and both codes.

If the site has reached its active-board limit, creation is refused with an explanation. Archive an existing board to free a slot, or ask the App Manager to raise the limit.

🔑 3 · Managing access

By default a board is open — anyone with the URL can view it and participate. You can protect the board with a User code when creating it or later from Edit Board.

Setting Effect How to set
Open access (default) Anyone with the board URL can participate Leave the User Access Code field empty
User code Visitors must enter the code before they can view or post Create or edit the board and type a unique code (e.g., TEAM2025)
💡 Note The User code protects ideas, lanes, and comments and must be unique within the site. The board title and basic access information can still appear on the code-entry screen. Share the User code with intended participants. It is distinct from the Manager code, which unlocks management controls. Treat both codes as credentials; neither verifies a participant's personal identity.

✎ 4 · Editing & duplicating boards

✎ Edit a board

Click the settings icon on a board card to open the edit form. You can change the title, description, submit-button label, User code, and board language.

⧉ Duplicate a board

Click the duplicate icon to create a new board with the same title (plus " (copy)"), description, submit-button label, language, lane names, colours, and saved lane order. Ideas, comments, and votes are not copied. Duplication needs an available active-board slot.

  • The User Access Code is not copied — assign a new one if needed.
  • A new Manager Code is generated automatically.

📦 5 · Archiving, Trash & recovery

📦 Archive a board

Click the archive icon on a board card. The board moves to the Archive tab and is set to Read-Only — users can view content but cannot post, vote, or comment.

To restore it to the active list, open the Archive page and click Unarchive. An active-board slot must be available. The board remains Read-Only until a manager turns off Lock board in the board editor and saves the change.

🗑 Move a board to Trash

Click the trash icon on an active board card and confirm. The board becomes unavailable at its URL, but its ideas, comments, and votes are retained. It no longer counts towards the active-board limit.

Open Trash to see when it was removed and by whom. Boards remain there until restored or permanently deleted; no automatic expiry is shown.

Restore or delete permanently In Trash, click Restore to recover the board and its content. An active board needs an available slot; an archived board returns to Archive without using a slot. Existing board sessions are invalidated when the board enters Trash, so reopen it and unlock again after recovery. To erase it, click Delete permanently and type the exact board name when prompted. Only this final deletion is irreversible and removes all its ideas, comments, and votes.

⬇ 6 · Exporting data

From the Boards dashboard, click Download my data in the header. This downloads a JSON file with account details and the site's active and archived boards, lanes, ideas, comments, and vote totals. Boards in Trash are excluded; restore one first if you need to export it. Manager codes are masked in this account export.

💡 Tip Keep an export for reference before significant structural changes or permanent deletion. An export is a downloadable record, not a one-click restore file; the app does not provide an import/restore-from-file screen.

Individual boards can also be exported by a board manager as CSV or JSON — see Part 2, Section 12.

Part 2
Board Manager
Control a specific board directly from the board page

Board Managers control a single board using a Manager Code. All board manager actions take place directly on the board page — there is no separate login. This section can be shared with anyone responsible for managing a board.

🔓 7 · Unlocking a board

💡 Site Managers: no code needed If you open a board URL while logged in as a Site Manager, manager controls activate automatically — you do not need to enter the Manager Code. This works whether you open the link from the admin panel or paste the board URL directly. Actual board managers still use the Manager Code as normal.

For board managers who access the board without a site manager login, follow the steps below.

1
Open the board URL in a browser

If the board is protected by a User Access Code, enter it first.

2
Click the settings gear icon

It appears in the top-right corner of the board header.

3
Enter your Manager Code

This is the 8-character code provided by your Site Manager. Once entered, manager controls become visible on the board.

💡 Shared or meeting-room devices A Manager-code unlock is held in the current tab's memory and is cleared on refresh. However, a signed-in Site Manager is automatically unlocked again. On a shared device, use Sign out in site administration first: it removes management access from all open board tabs on this application origin. Closing the administration tab alone does not do this.

👥 How participants experience the board

Understanding participant behaviour helps you moderate effectively and set realistic expectations in your sessions.

👤 Identity & anonymity

Participants are asked for a name when submitting an idea or comment, but it is entirely optional. Leaving it blank posts as Anonymous. The name field is free text — it is not verified or linked to any account. A moderator sees whatever name was typed, which may be nothing.

👍 How voting works

Participants can vote for any idea once and can undo their vote. The server links votes to a signed browser identity stored in a long-lived cookie; no account is required. Local browser storage also remembers which buttons were selected.

  • One vote per idea per browser identity, enforced by the server
  • Voting on a different browser or device counts as a new vote
  • There is no cap on total votes per person
  • There is no vote-only off switch; Read-Only stops votes together with idea submission and comments

For decisions where vote integrity matters, treat the totals as indicative rather than definitive.

✎ 8 · Editing board details

Once unlocked, click the pencil icon beside the board title to open the inline editor. Use the checkmark to save or the X to cancel. The information icon beside the title opens the optional board description.

FieldWhat it controls
Title The large heading at the top of the board page
Description Optional context or instructions opened with the information icon beside the title
"Add Idea" button label The text on the main action button — e.g., "Submit a suggestion" or "Share your idea"
Language Selects English, Finnish, or Swedish for built-in board interface labels. It does not translate existing titles, descriptions, lane names, ideas, comments, or custom button text.
Lock board (read-only) Stops new ideas, votes, and comments while keeping existing content visible

Click the checkmark to apply changes. Other open boards receive updates on their next refresh; if the header still shows old details, reload the page.

⋮⋮ 9 · Managing lanes

Lanes are the columns of the board. Each idea is assigned to a lane when submitted. Open Manage lanes (the Lane Settings dialog) to create, rename, recolour, reorder, or delete lanes.

✚ Add a lane

Click Manage lanes. Under Add New Lane, enter a name and choose a colour, then click Create Lane.

✎ Edit a lane

Open Manage lanes and click the pencil icon beside a lane. Update the name or colour and click Save lane.

🗑 Delete a lane

Open Manage lanes and click the trash icon beside a lane. This also removes all ideas currently in that lane.

Reorder lanes

Use the up/down arrows beside a lane in Lane Settings. Each move is saved automatically; wait for saving to finish before the next change. The first lane cannot move up and the last cannot move down. Save or cancel a lane edit before reordering.

The saved order is shared by desktop columns, mobile lane tabs, and lane choices in forms. It survives reloads and is copied when duplicating a board. New lanes are added at the end. Idea sorting is a separate control.

⚠ Warning Deleting a lane permanently removes all ideas in it. Move ideas to another lane before deleting if you want to keep them.

🛡 10 · Moderating content

Manager controls appear on each idea card when you are logged in as board manager.

✎ Edit an idea

Click the pencil icon on an idea card to edit its title and description inline. Click Save when done.

↔ Move an idea

Drag and drop (desktop): Hover the card to reveal the grip handle (⠿) at the top-left, then drag it to a different lane column and release.

Edit mode (any device): Click the pencil icon and use the lane picker at the bottom of the form, then click Save.

⇅ Sort ideas

Use the Sort dropdown in the board header to change the display order within every lane simultaneously:

  • Oldest first — submission order (default)
  • Newest first — most recent at the top
  • Most votes — highest vote count first

🗑 Delete an idea

Click the trash icon on an idea card. Confirm the deletion. This is permanent and also removes all comments on that idea.

🗑 Delete a comment

Expand an idea's comments and click the trash icon next to a comment. Useful for removing inappropriate content.

🔒 11 · Locking the board (Read-Only mode)

Locking prevents participants from submitting new ideas, voting, or commenting. Existing content remains fully visible. This is useful when a collection window has closed.

1
Open the board editor

Click the pencil beside the board title (requires manager access).

2
Toggle the Lock board switch

Turn on the switch, then click the checkmark to save. An amber banner indicates that the board is read-only. Other open tabs may need to refresh their board details to show the banner; the server enforces the saved restriction.

3
To unlock, toggle the switch off

Click the checkmark to save again. Idea submission, voting, and commenting are allowed again unless another access restriction applies.

⬇ 12 · Exporting board data

You can download all the content of a board at any time for offline analysis or reporting.

FormatBest for
CSV Opening in Excel, Google Sheets, or other spreadsheet tools; includes separate rows for ideas and comments
JSON Developer use, automated processing, or backup
1
Open the board with manager access active
2
Click the Export button in the board header
3
Choose CSV or JSON

The file downloads immediately to your default downloads folder.
