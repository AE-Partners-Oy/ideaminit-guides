# IdeaMinit user guides

Public documentation for IdeaMinit, published with GitHub Pages.

## Guides

- Management Manual — app managers, site managers, and board managers
- Board Manager Guide
- Participant Guide — English
- Osallistujan opas — Suomi
- Deltagarguide — Svenska

Open the website listed in this repository's About section to read the guides.
Readers do not need a GitHub account. Each guide can be printed or saved as a PDF
using the browser's Print command.

## Maintaining the guides

GitHub Pages publishes the root of the `main` branch. Upload the reviewed HTML
guides and update `index.html` when the documentation changes. Updates to `main`
are published automatically.

Only documentation belongs in this public repository. Do not upload application
source code, credentials, private configuration, database exports, or customer
information. The application repository remains separate.

The guide revision date is 20 November 2026. There is no automatic synchronisation
with the application repository; publish reviewed guide updates here separately.
